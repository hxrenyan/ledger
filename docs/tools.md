# 工具

小程序底部原来的「资产」挪到「我的」里。空出来的一栏是「工具」。

底部「工具」有两套，由服务端 `app_configs` 的 `tools.mode` 决定，管理后台「产品配置 → 工具页」切换：

| 模式 | 用户看到的 | 什么时候用 |
|---|---|---|
| `native`（默认，没写过也是这个） | 原生「联系人管理」，页面是 `miniprogram/pages/tool-contacts/` 和 `miniprogram/pages/contact-form/` | 提审、以及网页打不开时 |
| `h5` | `<web-view>` 打开 `/tools`，先 `POST /api/v1/webview/handoff` 换一次性码 | 后台切过去之后，用户下次进入这一栏 |

读配置失败、交接码失败、`web-view` 的 `binderror`，都退回原生列表，不留白屏。未登录只显示原生的登录卡，不打开网页。

`GET /api/v1/app/tools` 不用登录，返回 `{ mode: "native" | "h5" }`。`GET` / `PUT /api/v1/admin/tools`，body `{ mode }`，只接受这两个值。

原生这套再加一个工具，要加页面并重新发小程序。H5 这套再加一个工具，改 `web/src/pages/tools/` 后重新发布网页即可，不用发小程序。个人主体配不了业务域名，体验版和正式版上 H5 可能打不开，这时会退回原生。

联系人就是人情里的那些人，读写同一张 `contacts` 表、同一个 `/api/v1/contacts`。在这里改姓名、关系或日子，人情页的名单和顶部提醒一起变；在人情里新增的人，也会出现在这里。

- **列表**：可按姓名、关系、日子搜索，按全部 / 有日子 / 近期 / 已归档和关系筛选。点一张卡片编辑，点「往来」打开这个人的人情记录，点「归档」或「恢复」改归档状态。
- **编辑**：关系可点选常用标签或自己填。日子选填，点已有标签或「＋ 自定义」后选阳历 / 农历、月日，年份可空；再点已选标签或点「不填」清空。日子怎么记、顶部怎么提醒，见 [favors.md](favors.md)。

人情页上的「管理日子」直接打开这个列表。
