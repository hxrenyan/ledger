# 工具

小程序底部原来的「资产」挪到「我的」里。空出来的一栏是「工具」。

工具页是一个原生壳，里面用 `<web-view>` 打开 `/tools`。清单和每个工具的页面都在 `web/src/pages/tools/`。往后加一项，改网页并重新发布服务即可，不用发小程序。

第一个工具是联系人管理。这里的人就是人情里的联系人，读写同一张 `contacts` 表、同一个 `/api/v1/contacts`。在工具里改姓名、关系或日子，人情页的名单和顶部提醒一起变；在人情里新增的人，也会出现在这里。

- **联系人列表（`ContactsPage.vue`）**：顶栏提供「＋ 新增」入口；上方展示「联系人总数 / 已设日子 / 30 天内提醒」三格统计卡与近期重要日子横幅；支持按姓名、关系或日子关键词搜索，按「全部 / 有日子 / 近期提醒 / 已归档」及关系标签筛选，并支持直接编辑、归档/恢复或跳转小程序查看往来记录。
- **新增与编辑联系人（`ContactForm.vue`）**：关系支持点选常用标签（朋友、同事、亲戚等）或手动输入；日子不是必填，进入页面直接展示已有标签和「＋ 自定义」按钮，点选标签展开历法与日期，再次点击已选标签或点右上角「不填」即可清空；点「＋ 自定义」可输入新标签名并点「确定」（或直接回车、直接保存联系人时一并写入）。日子怎么记、顶部怎么提醒，见 [favors.md](favors.md)。

## 怎么打开

网页里没有 `wx.login`。小程序进入「工具」时：

1. `POST /api/v1/webview/handoff`（要登录，并带当前账本）
2. 打开 `{接口域名}/tools?handoff=<code>`
3. 网页 `POST /api/v1/auth/webview-session`，body `{ code }`，换回会话和当时的账本

码 5 分钟过期，用一次就失效，库里只存 SHA-256。换账本后再进「工具」会重新要一个码。

本地用开发者工具时，勾选「不校验合法域名、web-view（业务域名）」。真机要配业务域名，个人主体的小程序配不了，这一栏会打不开。资产、人情、明细仍是原生页。
