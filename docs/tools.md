# 工具

小程序底部原来的「资产」挪到「我的」里。空出来的一栏是「工具」。

底部「工具」有两套，由服务端 `app_configs` 的 `tools.mode` 决定，管理后台「产品配置 → 工具页」切换：

| 模式 | 用户看到的 | 什么时候用 |
|---|---|---|
| `native`（默认，没写过也是这个） | 原生清单：联系人管理、日历记录。页面是 `miniprogram/pages/tool-contacts/`、`miniprogram/pages/contact-form/`、`miniprogram/pages/tool-calendar/` | 提审、以及网页打不开时 |
| `h5` | `<web-view>` 打开 `/tools`，先 `POST /api/v1/webview/handoff` 换一次性码 | 后台切过去之后，用户下次进入这一栏 |

读配置失败、交接码失败、`web-view` 的 `binderror`，都退回原生清单，不留白屏。未登录只显示原生的登录卡，不打开网页。

`GET /api/v1/app/tools` 不用登录，返回 `{ mode: "native" | "h5" }`。`GET` / `PUT /api/v1/admin/tools`，body `{ mode }`，只接受这两个值。

原生这套再加一个工具，要加页面并重新发小程序。H5 这套再加一个工具，改 `web/src/pages/tools/` 后重新发布网页即可，不用发小程序。个人主体配不了业务域名，体验版和正式版上 H5 可能打不开，这时会退回原生。

## 已知问题：两套页面仍是两份代码

原生和 H5 是两份页面，没有共用界面。原生在 `miniprogram/pages/tools/`、`tool-contacts/`、`contact-form/`、`tool-calendar/`、`favor-person/`、`gift-form/`；H5 在 `web/src/pages/tools/`。改一边不会改另一边。原生还要重新发小程序才到用户手里，H5 重新发布网页即可。后面再加工具或改交互，要同时改这两处，否则会继续漂。

接口和数据是同一套。联系人、日子、日历记事、往来记录，两边现在都能做。还没对齐的只剩这些展示差异：

- H5 联系人列表在筛选上方有「近期重要日子」横幅，30 天内每个日子一张卡。原生没有这条横幅。顶部「30天内」和「近期」两边都按人数计。
- H5 日历输入框可以用 Ctrl/⌘+Enter 保存、Esc 取消修改。手机上键盘弹出后，点「记下」会在按下时提交，避免收起键盘把这一下点丢了。原生同样在按下时提交，键盘上方的「完成」也会记下。

## 联系人管理

联系人就是人情里的那些人，读写同一张 `contacts` 表、同一个 `/api/v1/contacts`。联系人属于账本主人账号，同一个主人在多个账本共用联系人；打开共享账本时显示并维护主人账号的联系人，不会切换为当前成员自己的联系人。在这里改姓名、关系或日子，人情页的名单和顶部提醒一起变；在人情里新增的人，也会出现在这里。送出、收到和差额仍按当前账本的人情记录计算。

- **列表**：可按姓名、关系、日子搜索，按全部 / 有日子 / 近期 / 已归档和关系筛选。点一张卡片编辑，点「归档」或「恢复」改归档状态。未归档的人可以点「往来」。H5 另外有「近期重要日子」横幅，见上面「已知问题」。
- **往来**：看这个人的送出、收到和差额，以及每条事由、日期、备注。可以追加、修改、删除。新记一笔时可以勾选「同时记入明细」，选账户和分类后，同一金额再写一笔流水并计入余额。改一条时可以「转成明细」：这条人情删掉，按当前金额、日期、备注和所选账户、分类写成流水。H5 路径是 `/tools/contacts/:id/records`，记一笔是 `/tools/contacts/:id/gifts/new`，改一条是 `/tools/gifts/:id`。原生打开 `pages/favor-person/`，记和改走 `pages/gift-form/`。
- **编辑**：关系可点选常用标签或自己填。日子可以记多个，最多 8 个。点已有标签或「＋ 自定义」后选阳历 / 农历、月日，年份可空，再点「加入这个日子」。点已加入的那条可以改或删。日子怎么记、顶部怎么提醒，见 [favors.md](favors.md)。

人情页上的「管理日子」直接打开这个列表。H5 路径是 `/tools/contacts`。

## 日历记录

按天记下要办的事。记事只跟登录用户走，不跟账本。换一本账，这些记事还在。同账本的其他人看不到，也改不了。微信账号合并时，记事并到留下的那个账号。不进流水，也不动余额、收据和统计。

明细页右下角 + 里的「日历记录」按住说话。语音在手机上用微信同声传译插件转成文字，不上传录音，也不看后台有没有语音模型。转写之后先拆日期和事情：没说日期就落在今天；说了今天、明天、后天、星期、几月几号、月底这类阳历说法，就落到对应那一天。转写写成「下个周一」「周5」「10月20」「20好」「2026-10-20」「二五年十月二十号」时同样认。事情是去掉日期后剩下的正文。一句里说到多个日期，就按日期拆成多条。核对日期和正文后再记下。只说了日期、没听出事情时要补上才能保存。农历说法不换算，整句仍按今天的记事留给用户改。超过 200 字会截断后再改。不进流水，也不动余额、收据和统计，这一步不扣积分。打开日历页仍从底部「工具」进入。

`POST /api/v1/day-notes/parse`，body `{ text }`，返回 `{ items: [{ day, body, clipped }] }`。只识别，不落库。`text` 空白或超过 4000 字拒绝。

一天可以有多条。每条只有一段文字，1–200 字。日期是上海日历的 `YYYY-MM-DD`，可以记过去，也可以记还没到的日子。列表按写入时间从早到晚。

页面由「月历卡 + 当天记事卡 + 记事一览卡」三段组成，层次分明，不再把月历夹在当天标题与记事列表中间。

- **月历卡**：顶栏左侧是月份切换（左右箭头切月、点年月弹选择器跳月），右侧是「回今天」（不在今天时出现）和「收起日历 / 展开日历」（开合状态记在本地，下次进入保持上次的样子）。展开时显示紧凑 7 列月历，支持左右滑动切月；一条记事显示圆点、多条显示条数、今天带描边、选中日实色高亮。收起时只保留顶栏，切月与回今天依然可用。
- **当天记事卡**：顶栏左侧是前一天 / 日期标题（含「今天 / 明天」等相对标签与当天条数）/ 后一天，右侧是醒目的「＋ 记一条」按钮。点「＋ 记一条」（或当天为空时直接点空白提示框）就在紧下方展开输入框，带字数统计与「取消 / 记下」；再点一次「收起」即可关掉。每条记事下方有宽松好点的「编辑」「删除」按钮，点「编辑」在原位置就地修改。
- **记事一览卡**：默认展开，顶栏显示本月总条数与记录天数，右侧可一键切换「本月」全部记事或「今起」待办安排，也可点标题收起。下方搜索框为空时展示当前筛选结果；输入关键词自动扩到选中月前后各 5 个月（合计 11 个月，不超过接口的一年上限）跨月搜索并标出范围。列表按天分组，每组头部可直接点「＋ 记一条」给那天加记事，每条记事右侧可直接点「编辑」或「删除」，点日期或正文则会切换到那天并滚回当天记事卡。

某一天删空后，月历上的标记消失。刷新过程中切换日期，返回后按当前选中日期展示最新记事，日期标题与列表保持一致。保存期间可以切换日期、开始另一条记事或继续输入；旧请求返回只结束原编辑会话，不会清掉新草稿或覆盖新会话的错误提示。同一条新增记事在等待保存时继续输入，返回后保留正文，下一次保存修改刚创建的记录，不会重复新增。

接口都要登录，并且带当前账本，用来确认这个人进得了工具。数据只按当前用户读写。

- `GET /api/v1/day-notes?month=2026-10` → `{ month, days: [{ day, count }], items: [{ id, day, body, created_at, updated_at }] }`
- `GET /api/v1/day-notes?day=2026-10-19` → `{ day, items: [{ id, day, body, created_at, updated_at }] }`
- `GET /api/v1/day-notes?from=2026-01-01&to=2026-12-31` → `{ from, to, days: [{ day, count }], items: [{ id, day, body, created_at, updated_at }] }`。`from`、`to` 都含当天，必须同时给出，且 `to` 不能晚于 `from` 加一年。
- `POST /api/v1/day-notes`，body `{ day, body }`，返回刚写下的那条
- `PATCH /api/v1/day-notes/:id`，body `{ body }`，改正文
- `DELETE /api/v1/day-notes/:id` → `{ ok: true }`

月份、某一天、时间范围三者只能指定一个。只给了 `from` 或只给了 `to`、开始晚于结束、跨度超过一年，接口拒绝。正文空着、超过 200 字、日期不是合法的 `YYYY-MM-DD`，同样拒绝。改或删别人的条目，当作不存在。

原生页面是 `miniprogram/pages/tool-calendar/`。H5 路径是 `/tools/calendar`。
